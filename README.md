# Multimodal Phishing Detection for AI-Generated Phishing Attacks

## What This Project Does

This project builds a system that automatically classifies emails into three categories:

- **Class 0 — Legitimate** — genuine emails
- **Class 1 — Human Phishing** — phishing emails written by humans
- **Class 2 — AI Phishing** — phishing emails generated by AI models

The key challenge is that AI-generated phishing emails look identical to legitimate emails — perfect grammar, professional tone, no suspicious links. Existing systems cannot detect them. This project addresses that gap.

---

## How It Works

The system combines two modules:

1. **Stylometric module** — extracts 63 handcrafted writing style features from each email (word length, vocabulary richness, readability scores, URL counts, etc.)
2. **ModernBERT module** — a fine-tuned transformer model that reads and understands the email content, producing 3 confidence scores
3. **XGBoost fusion** — combines all 66 features and classifies the email

The entire system runs **offline on local hardware** — no email data is sent to any external service.

---

## Key Results

| System | Macro F1 | BEC Detection |
|--------|----------|---------------|
| Zero-shot LLM | 0.6247 | 1.4% |
| Our Original System | 0.9900 | 2.7% |
| Our Diverse System | 0.9879 | 99.8% |

**Most important finding:** High internal accuracy (99%) can mask near-complete failure on phishing from unseen AI sources (2.7%). Training data diversity across AI models is the critical factor.

## Complete Setup — Step by Step

### Step 1 — Install Anaconda

Download and install Anaconda from:
```
https://www.anaconda.com/download
```

This gives you Python, Jupyter Notebooks, and package management all in one.

### Step 2 — Create Project Environment

Open Anaconda Prompt (search in Windows Start menu) and run:

```bash
conda create -n phishing_detection python=3.10 -y
conda activate phishing_detection
```

You should see `(phishing_detection)` at the start of your prompt.

### Step 3 — Clone This Repository

```bash
git clone https://github.com/taniya-j/Research-Project.git
cd Research-Project
```

### Step 4 — Install All Dependencies

```bash
pip install -r requirements.txt
```

This installs all required Python libraries. It may take 5-10 minutes.

### Step 5 — Install SpaCy Language Model

```bash
python -m spacy download en_core_web_sm
```

This downloads the English language model used for grammatical analysis.

### Step 6 — Install Ollama (for local LLM)

Download Ollama from:
```
https://ollama.com
```

After installing, open a terminal and run:
```bash
ollama pull qwen2.5:3b
```

This downloads the Qwen2.5 3B language model (about 2GB). Keep Ollama running whenever you use notebooks 03 or 05.

### Step 7 — Set Up Kaggle API

1. Go to https://kaggle.com and create an account
2. Click your profile picture → Settings → API → Create New Token
3. This downloads a file called `kaggle.json`
4. Place this file at:
   - Windows: `C:\Users\YourName\.kaggle\kaggle.json`
   - Mac/Linux: `~/.kaggle/kaggle.json`

### Step 8 — Start Jupyter Notebooks

In Anaconda Prompt with the environment activated:

```bash
cd C:/path/to/Research-Project
jupyter notebook
```

A browser window will open. You can now run the notebooks.

## Running the Project — Notebook Order

Run notebooks in this exact order. Each notebook saves its output as CSV files that the next notebook uses.

---

### Notebook 01 — Data Preparation
**File:** `notebooks/01_data_prep.ipynb`
**What it does:** Downloads email datasets from Kaggle and prepares them for analysis
**Runtime:** 5-10 minutes (excluding downloads)
**Output:** `data/processed/dataset_final.csv`

**Before running:**
- Make sure Kaggle API is configured (Step 7 above)
- Create these folders if they do not exist:
  ```
  data/raw/
  data/processed/
  data/generated/
  models/
  results/
  ```

---

### Notebook 02 — Stylometric Feature Extraction
**File:** `notebooks/02_stylometric.ipynb`
**What it does:** Extracts 63 writing style features from every email using NLTK, SpaCy, and Textstat
**Runtime:** 10-20 minutes
**Output:** `data/processed/stylometric_features_final.csv`

---

### Notebook 03 — AI Phishing Generation
**File:** `notebooks/03_ai_phishing_generation.ipynb`
**What it does:** Generates 2,492 AI phishing emails using Qwen2.5 3B across 5 scenarios
**Runtime:** Approximately 14 hours — designed to run overnight
**Output:** `data/generated/ai_phishing_all.csv`

**Important:**
- Start Ollama before running: open a separate terminal and run `ollama serve`
- The notebook saves progress every 50 emails — if interrupted, it can resume
- Pre-generated output is already saved if you downloaded the full repository

---

### Notebook 04 — Dataset Finalisation
**File:** `notebooks/04_dataset_finalisation.ipynb`
**What it does:** Combines all data sources into the final balanced dataset
**Runtime:** 15-20 minutes
**Output:** `data/processed/dataset_final.csv` (10,492 emails)

---

### Notebook 05 — Zero-Shot LLM Processing
**File:** `notebooks/05_llm_batch_processing.ipynb`
**What it does:** Sends all emails to Qwen2.5 3B for zero-shot classification
**Runtime:** Approximately 16 hours — designed to run overnight
**Output:** `data/processed/llm_features.csv`

**Important:**
- Start Ollama before running: `ollama serve`
- This notebook demonstrates that zero-shot LLMs detect only 1.4% of AI phishing
- Pre-generated output is already saved if you downloaded the full repository

---

### Notebook 05b — ModernBERT Fine-tuning (Google Colab)
**File:** `notebooks/05b_modernbert_finetuning.ipynb`
**What it does:** Fine-tunes ModernBERT on our labelled dataset using Google Colab GPU
**Runtime:** 12-15 minutes on T4 GPU
**Output:** Saved to Google Drive

**How to run on Colab:**
1. Go to https://colab.research.google.com
2. Upload this notebook: File → Upload notebook
3. Enable GPU: Runtime → Change runtime type → T4 GPU
4. Mount your Google Drive when prompted
5. Upload `dataset_final.csv` to Google Drive at `phishing_detection/data/processed/`
6. Run all cells
7. Download the output CSV files back to your local `data/processed/` folder

**Output files to download from Google Drive:**
- `modernbert_features.csv`
- `bec_modernbert.csv`

---

### Notebook 06 — Fusion Classifier
**File:** `notebooks/06_fusion_classifier.ipynb`
**What it does:** Trains the XGBoost fusion classifier and evaluates on test set
**Runtime:** 2-3 minutes
**Output:** `models/xgboost_modernbert.pkl`, evaluation graphs in `results/`

---

### Notebook 07 — Baselines
**File:** `notebooks/07_baselines.ipynb`
**What it does:** Trains and evaluates five baseline comparison models
**Runtime:** 5-10 minutes
**Output:** Baseline comparison results and graphs

---

### Notebook 08 — Full Evaluation
**File:** `notebooks/08_evaluation.ipynb`
**What it does:** Runs all three evaluation scenarios and benchmark comparison
**Runtime:** 5-10 minutes
**Output:** All scenario graphs in `results/`

---

### Notebook 09 — Data Cleaning and Diverse Retraining
**File:** `notebooks/09_data_cleaning_retraining.ipynb`
**What it does:** Removes salutation artefacts, adds Gemini BEC data, retrains diverse system
**Runtime:** 15-25 minutes (plus another Colab run for ModernBERT)
**Output:** `data/processed/dataset_diverse.csv`, `models/xgboost_diverse.pkl`
