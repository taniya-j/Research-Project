# Data

Raw data files are not included in this repository due tosize and licensing constraints.

## Download Instructions

1. Enron Email Dataset (legitimate emails)
   kaggle datasets download -d wcukierski/enron-email-dataset

2. Nazario Phishing Corpus (human phishing)
   kaggle datasets download -d subhajournal/phishingemails

3. Supplementary phishing dataset
   kaggle datasets download -d naserabdullahalam/phishing-email-dataset

4. Adversarial BEC Email Dataset (AI phishing, CC-BY-4.0)
   Available on Kaggle — search Adversarial BEC Email Dataset

## Folder Structure
Place downloaded files in:
   data/raw/enron/
   data/raw/nazario/
   data/raw/ai_phishing/
   data/raw/external_test/

## Processed Files
Processed CSV files are generated by running the notebooks in order.
